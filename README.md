Практический fullstack-проект с адаптивной стилизацией интерфейса с использованием Tailwind CSS.

   О проекте

Проект представляет собой простой интернет-магазин одежды.

В приложении реализованы:

- адаптивная сетка карточек товаров;
- адаптивная навигация;
- страница входа;
- состояния `hover`, `focus` и `disabled`;
- получение товаров через API;
- взаимодействие frontend и backend;
- адаптивное отображение на мобильных устройствах, планшетах и компьютерах.

    Технологии

   Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Axios

   Backend

- Node.js
- Express
- TypeScript
- CORS
- dotenv
